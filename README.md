# VELT — Scent that stays.

VELT is a luxury fragrance e-commerce experience built with React and Vite.

The project was developed as part of my frontend learning journey with The Odin Project, with a focus on building a polished, component-based shopping experience rather than a simple tutorial demo.

## ✨ Live Preview

[View VELT Live](https://hadiswebpro.github.io/shopping-cart-odin/)

## Features

- Luxury editorial-inspired fragrance storefront
- Responsive design for desktop, tablet, and mobile
- Product collection with fragrance categories
- Product detail pages
- Search fragrances from the navigation bar
- Filter the collection by scent family
- Favorites system
- Shopping bag with quantity controls
- Add and remove products from the cart
- Dynamic cart item count
- Responsive mobile navigation
- GitHub Pages deployment with GitHub Actions

## 🛠️ Built With

- React
- JavaScript
- Vite
- React Router
- CSS Modules
- GitHub Actions

## 🚀 Run Locally

Clone the repository and install the dependencies:

```bash
git clone https://github.com/hadiswebpro/shopping-cart-odin.git
cd shopping-cart-odin
npm install
npm run dev
```

For a production build:

```bash
npm run build
npm run preview
```
